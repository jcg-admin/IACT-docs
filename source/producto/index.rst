###################
Dominio de Producto
###################

El Dominio de Producto constituye la base de requisitos funcionales y lógicas de negocio del proyecto IACT. Su objetivo es documentar las necesidades estratégicas que deben ser satisfechas por la solución técnica.

Este dominio se divide en dos secciones fundamentales:

.. grid:: 1 2 2 2
   :gutter: 3

   .. grid-item-card:: Reglas de Negocio (BR)
      :link: reglas-negocio/index
      :link-type: doc

      Restricciones lógicas y operativas que rigen el comportamiento del sistema y la integridad de los datos.

   .. grid-item-card:: Casos de Uso (UC)
      :link: casos-uso/index
      :link-type: doc

      Definición de las interacciones entre los usuarios finales y la interfaz del Dashboard de Analytics.
