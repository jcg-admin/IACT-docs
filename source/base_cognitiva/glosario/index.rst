=========
Glosario
=========

Propósito
=========

El **Glosario** contiene el vocabulario oficial del proyecto IACT, estableciendo 
definiciones precisas de términos técnicos y de negocio utilizados en la documentación.

Este subdominio elimina la ambigüedad semántica y proporciona un lenguaje común 
para todos los participantes del proyecto.

Cómo Usar el Glosario
======================

El glosario está organizado alfabéticamente y cada término incluye:

* **Definición:** Descripción clara y concisa del concepto
* **Contexto:** Cómo se usa el término en el proyecto IACT
* **Sinónimos:** Términos equivalentes o relacionados (si aplican)
* **Referencias:** Enlaces a documentación relacionada

.. note::
   Los términos del glosario son referenciados en requisitos, casos de uso y 
   especificaciones técnicas para garantizar consistencia en la documentación.
