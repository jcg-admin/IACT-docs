==============================================================
Iniciativa: Plan Maestro Iniciativas Pendientes
==============================================================

Consolida las **20 iniciativas candidatas** registradas como
deuda durante las 15 iniciativas cerradas en la sesion
2026-05-19. Por cada una documenta:

* ``repo_objetivo``
* Origen (que iniciativa la levanto)
* Prioridad (P1 critica / P2 alta / P3 media / P4 baja)
* **FASES** segun PROC-GOB-013 v2.0.0
  (DISCOVER -> SCOPE -> ESTRUCTURA -> EJECUTAR -> CIERRE)
* **Tareas atomicas T-NNN** (cada una toca exactamente un
  archivo, criterio de aceptacion verificable)

Este plan es el insumo para abrir iniciativas
``feature/<wp-slug>`` cuando el sponsor decida cual atacar.
Cada bloque del plan se puede convertir en su iniciativa
real copiando la lista de tareas y ejecutandolas.
