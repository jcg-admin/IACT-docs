==============
Base Cognitiva
==============

Propósito del Dominio
=====================

La **Base Cognitiva** establece el fundamento semántico, conceptual
y estructural del proyecto IACT. Provee el **vocabulario base** que
todos los demás cajones de la documentación consumen.

Responde a la pregunta: **"¿Qué significan los conceptos que
usamos?"**.

Contenido
=========

- **Lenguaje común:** vocabulario oficial y términos técnicos del
  proyecto.
- **Base semántica:** definiciones precisas que eliminan
  ambigüedad cross-dominio.
- **Fundamento teórico:** marco conceptual que sustenta el modelo
  de análisis.
- **Trazabilidad:** base para la interpretación correcta de
  requisitos, restricciones, ADRs.
