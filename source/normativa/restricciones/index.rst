.. _restricciones:

==============
Restricciones
==============

Propósito
=========

Este subdominio documenta las **restricciones técnicas y documentales** del proyecto IACT, 
estableciendo limitaciones conocidas que afectan el desarrollo.

Contenido
=========

Las restricciones incluyen:

* Restricciones técnicas (plataforma, tecnología, rendimiento)
* Restricciones documentales (formatos, herramientas)
* Restricciones organizacionales (recursos, tiempo)
* Limitaciones conocidas del sistema

.. note::
   Contenido en desarrollo. Las restricciones se documentarán conforme se 
   identifiquen durante el desarrollo del proyecto.
