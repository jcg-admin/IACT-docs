.. _gobernanza:

===========
Gobernanza
===========

Propósito
=========

Este subdominio establece las **políticas de gobierno** del proyecto IACT, 
definiendo procesos de control, aprobación y responsabilidades.

Contenido
=========

La gobernanza incluye:

* Modelo de gobernanza del proyecto
* Roles y matriz RACI
* Control de calidad documental
* Procesos de aprobación

.. note::
   Contenido en desarrollo. Las políticas de gobernanza se definirán conforme 
   se establezca la estructura del equipo.
