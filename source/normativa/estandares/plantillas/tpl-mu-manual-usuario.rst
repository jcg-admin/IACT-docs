TPL_MU: Plantilla de Manual de Usuario
==========================================

.. note::

 Plantilla para manuales de usuario final del producto IACT.
 Aplica skill ``ba-solution-evaluation``.

=================

   - Español

2. Tabla de contenidos
======================

1. Introducción
2. Primeros pasos (login, navegación)
3. Funcionalidades principales (por UC)
4. Configuración personal
5. FAQ
6. Soporte

3. Por funcionalidad
====================

Cada sección de funcionalidad debe incluir:

- ¿Qué hace?
- ¿Cuándo usarla?
- Pasos numerados con screenshots.
- Casos comunes de error y cómo resolverlos.

4. Convenciones visuales
========================

- Pasos numerados.
- Capturas de pantalla con anotaciones.
- Avisos: ``.. note::`` (info), ``.. warning::`` (cuidado),
  ``.. tip::`` (atajo útil).
