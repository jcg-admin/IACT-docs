Quick Start (5 Minutes)
=======================

Get IACT running in 5 minutes.

1. Install & Start (2 min)
--------------------------

.. code-block:: bash

   # Clone and install
   git clone https://github.com/your-org/iact.git
   cd iact
   npm install

   # Start dev server
   npm start

Open `http://localhost:3000 <http://localhost:3000>`_

2. Explore (3 min)
------------------

You should see:
- Header with logo, user menu, notifications
- Sidebar with navigation links
- Main dashboard content

Try:
- Click menu button on mobile
- Click sidebar links
- Click user menu dropdown
