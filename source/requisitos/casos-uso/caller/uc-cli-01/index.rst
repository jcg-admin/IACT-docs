==============================================
UC_CLI_01 — Iniciar Llamada al Call Center
==============================================

Resumen: cliente externo llama al
numero del call center. NO hay RBAC
(actor externo). Sistema responde
con saludo + IVR.

Este UC modela la perspectiva del
**cliente como usuario de la
maquina** (UML-06).
