.. _casos-uso:

===========
Casos de Uso
===========

Propósito
=========

Este subdominio contiene los **Casos de Uso (UC)** del proyecto IACT, 
describiendo las interacciones entre actores y el sistema para lograr objetivos específicos.

Los casos de uso derivan de las reglas de negocio y generan requisitos funcionales.

Contenido
=========

Los casos de uso incluyen:

* Actores del sistema
* Precondiciones y postcondiciones
* Flujo principal
* Flujos alternativos y de excepción
* Trazabilidad a reglas de negocio

Prefijo
=======

Los artefactos de este subdominio usan el prefijo **UC_** (Use Case).

Ejemplo: ``UC_001_Visualizar_Dashboard.rst``

.. note::
   Contenido en desarrollo. Los casos de uso se documentarán conforme 
   se identifiquen las interacciones del sistema.
