FR-042.02: Eliminar asignación de segmento
==============================================================================

2. Especificación
-----------------

**Declaración:**

   El sistema DEBE eliminar los registros de asignación usuario-centro
   CUANDO la validación de mínimo un segmento es exitosa y el admin
   confirma la revocación.

**Descripción:**

   Proceso de revocación:
   
   1. Valida nuevamente mínimo un segmento restante
   2. Marca registros como revocados o los elimina
   3. Registra metadata de revocación
   4. Registra evento en auditoría
   5. Actualiza filtros de sesión del usuario
   
   **Efecto Inmediato:**
   
   El usuario pierde acceso a datos del segmento revocado
   inmediatamente en su siguiente consulta.

----

3. Criterio de Aceptación
-------------------------

::

   DADO validación exitosa y confirmación
   CUANDO se ejecuta la revocación
   ENTONCES se eliminan los registros de segmentación
   
   Escenario 1: Revocación simple
   DADO segmento "Centro Sur" seleccionado para revocar
   CUANDO se confirma
   ENTONCES el registro de user_segments se elimina/marca
   Y se registra en auditoría
   
   Escenario 2: Revocación múltiple
   DADO 2 segmentos seleccionados (de 3 totales)
   CUANDO se confirma
   ENTONCES ambos registros se eliminan
   Y queda 1 segmento activo
   
   Escenario 3: Efecto inmediato en datos
   DADO usuario con sesión activa viendo datos de "Centro Sur"
   CUANDO se le revoca "Centro Sur"
   ENTONCES siguiente consulta no incluye datos de "Centro Sur"
   
   Escenario 4: Auditoría
   DADO revocación completada
   CUANDO se registra
   ENTONCES event_type = 'SEGMENT_REVOKED'
   Y details contiene centros revocados
