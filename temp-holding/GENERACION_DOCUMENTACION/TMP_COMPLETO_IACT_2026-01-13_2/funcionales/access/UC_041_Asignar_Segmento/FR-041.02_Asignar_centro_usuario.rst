FR-041.02: Asignar centro a usuario

2. Especificación
-----------------

**Declaración:**

   El sistema DEBE crear registros de asignación usuario-centro
   CUANDO el admin confirma la asignación de segmentos.

**Descripción:**

   Proceso de asignación:
   
   1. Valida que centros seleccionados existen y están activos
   2. Verifica que no estén ya asignados
   3. Crea registro por cada centro seleccionado
   4. Registra evento en auditoría
   
   **Estructura del Registro:**
   
   .. list-table::
      :widths: 25 20 55
      :header-rows: 1
   
      * - Campo
        - Tipo
        - Valor
      * - id
        - UUID
        - Generado
      * - user_id
        - UUID
        - ID del usuario
      * - center_id
        - UUID
        - ID del centro
      * - assigned_at
        - TIMESTAMP
        - NOW()
      * - assigned_by
        - UUID
        - ID del admin

----

3. Criterio de Aceptación
-------------------------

::

   DADO centros seleccionados para asignar
   CUANDO admin confirma
   ENTONCES se crean los registros de segmentación
   
   Escenario 1: Asignación simple
   DADO centro "Centro Norte" seleccionado
   CUANDO se confirma
   ENTONCES existe registro user_segments con center_id correspondiente
   Y assigned_by = ID del admin
   
   Escenario 2: Asignación múltiple
   DADO 3 centros seleccionados
   CUANDO se confirma
   ENTONCES se crean 3 registros en user_segments
   Y todos tienen misma fecha de asignación
   
   Escenario 3: Centro ya asignado
   DADO intento de asignar centro ya existente
   CUANDO se procesa
   ENTONCES se ignora (no duplica)
   Y se notifica que ya estaba asignado
   
   Escenario 4: Auditoría
   DADO asignación completada
   CUANDO se registra
   ENTONCES event_type = 'SEGMENT_ASSIGNED'
   Y details contiene centros asignados
