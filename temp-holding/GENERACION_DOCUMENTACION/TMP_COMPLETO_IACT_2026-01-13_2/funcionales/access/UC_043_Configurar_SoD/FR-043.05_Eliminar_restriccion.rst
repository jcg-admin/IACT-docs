2. Especificación
-----------------

**Declaración:**

   El sistema DEBE permitir eliminar restricciones SoD CUANDO el admin
   determina que ya no son necesarias, tras confirmación.

**Descripción:**

   Proceso de eliminación:
   
   1. Admin selecciona restricción a eliminar
   2. Sistema solicita confirmación
   3. Muestra advertencia de implicaciones
   4. Admin confirma con motivo
   5. Sistema elimina/desactiva restricción
   6. Registra evento en auditoría
   
   **Implicaciones:**
   
   - Funciones antes incompatibles podrán asignarse juntas
   - No afecta asignaciones existentes
   - Se pierde la validación de control

----

3. Criterio de Aceptación
-------------------------

::

   DADO admin eliminando restricción SoD
   CUANDO confirma la eliminación
   ENTONCES la restricción deja de aplicarse
   
   Escenario 1: Eliminación con confirmación
   DADO restricción ACC-001/ACC-005
   CUANDO admin confirma eliminación
   ENTONCES la restricción se marca como eliminada
   Y se registra en auditoría
   
   Escenario 2: Motivo obligatorio
   DADO solicitud de eliminación
   CUANDO no se ingresa motivo
   ENTONCES se muestra "Debe indicar motivo de eliminación"
   
   Escenario 3: Efecto en asignaciones
   DADO restricción eliminada
   CUANDO admin intenta asignar funciones antes incompatibles
   ENTONCES la asignación se permite sin advertencia
   
   Escenario 4: Advertencia previa
   DADO intento de eliminación
   CUANDO se muestra confirmación
   ENTONCES incluye advertencia:
      "Al eliminar esta restricción, será posible asignar
       ACC-001 y ACC-005 al mismo usuario"
