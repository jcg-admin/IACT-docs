2. Especificación
-----------------

**Declaración:**

   El sistema DEBE mostrar todas las restricciones SoD configuradas
   CUANDO el admin accede a la configuración de SoD.

**Descripción:**

   El listado muestra:
   
   **Por cada Restricción:**
   
   - Función A (código y nombre)
   - Función B (código y nombre)
   - Severidad (HARD/SOFT)
   - Descripción/Motivo
   - Fecha de creación
   - Creado por
   - Estado (Activa/Inactiva)
   
   **Funcionalidades:**
   
   - Filtro por severidad
   - Filtro por módulo
   - Búsqueda por código de función
   - Ordenamiento por columnas
   - Acciones: Editar, Eliminar

----

3. Criterio de Aceptación
-------------------------

::

   DADO admin en configuración de SoD
   CUANDO carga la vista
   ENTONCES ve listado de todas las restricciones
   
   Escenario 1: Lista completa
   DADO 10 restricciones SoD configuradas
   CUANDO se carga la pantalla
   ENTONCES se muestran las 10 restricciones
   Y cada una tiene sus datos completos
   
   Escenario 2: Filtro por severidad
   DADO filtro severidad = HARD
   CUANDO se aplica
   ENTONCES solo se muestran restricciones HARD
   
   Escenario 3: Sin restricciones
   DADO sistema sin restricciones SoD
   CUANDO se carga la pantalla
   ENTONCES se muestra "No hay restricciones configuradas"
   Y botón "Crear primera restricción"
   
   Escenario 4: Acciones disponibles
   DADO restricción visible en lista
   CUANDO admin hace clic en acciones
   ENTONCES ve opciones: Ver detalle, Editar, Eliminar
