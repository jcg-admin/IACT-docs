************************************
Requisitos del sistema y de la persona usuaria
************************************

Existen muchos recursos gratuitos (y de pago) para aprender más sobre
`SQL`_ y `Oracle`_. Sin embargo, antes de hablar de optimización de
consultas SQL o de código PL/SQL, es necesario dominar los conceptos
básicos de SQL.

Este manual está pensado para personas con **al menos algo de
experiencia práctica** usando SQL y PL/SQL contra una base de datos
Oracle en un entorno real de trabajo, en particular desarrolladoras o
personas que aspiran a serlo.

Si únicamente has trabajado con bases de datos de ejemplo, probablemente
no obtendrás todo el provecho de este material. Es posible que puedas
seguir algunos ejemplos, pero el enfoque principal es la optimización en
entornos de producción.

Se recomienda leer el manual completo, en especial si aún no tienes
mucha experiencia. Los temas están organizados para ir **de lo más
básico a técnicas de optimización más avanzadas**.

Dado que este manual es un trabajo en progreso, se irán añadiendo más
secciones y ejemplos con el tiempo. Algunas partes pueden resultar de
poco interés para personas con mucha experiencia; otras, aun siendo
avanzadas, podrían aportar ideas útiles incluso a quienes ya trabajan de
forma profesional.

Si deseas contribuir a este proyecto (ya sea al contenido original o a
la adaptación en español), visita el `repositorio público`_ y abre un
issue o un pull request.

Y si tienes dudas o comentarios, también puedes usar ese canal para
contactar.
